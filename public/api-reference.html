Neyome API Reference

REST API for the Neyome family rewards app and admin dashboard. All JSON responses use a common envelope unless noted otherwise.

Response envelope

{
  "success": true,
  "message": "Human-readable message",
  "data": { }
}

Errors return success: false with an appropriate HTTP status (4xx/5xx) and message.

Public endpoints No auth

Prefer these routes in mobile/web clients — no API key in the app binary.
Locale: send X-Locale: ar or Accept-Language: ar (supported: en, ar, de). Responses return localized question/answer or title/body strings, not all languages at once.

App authentication JWT parent

POST /auth/register

Register a parent account; creates family + returns JWT.

Request body{
  "email": "parent@example.com",
  "password": "SecurePass123",
  "name": "Parent Name",
  "locale": "en"
}
Response{
  "success": true,
  "data": { "user": { ... }, "accessToken": "eyJhbG..." }
}
POST /auth/login 
Request body{ "email": "parent@example.com", "password": "SecurePass123" }
POST /auth/forgot-password

Sends 6-digit OTP to email (10 min). Parent accounts only.

Request{ "email": "parent@example.com" }
POST /auth/reset-password 
Request{
  "email": "parent@example.com",
  "otp": "482913",
  "newPassword": "NewSecurePass123"
}
POST /auth/change-email/request Bearer JWT

Step 1 — OTP sent to the new email (10 min).

RequestAuthorization: Bearer <token>

{ "newEmail": "newparent@example.com" }
Response{
  "success": true,
  "data": { "expiresInMinutes": 10 }
}
POST /auth/change-email/verify Bearer JWT

Step 2 — confirm OTP; returns new JWT with updated email claim.

Request{
  "newEmail": "newparent@example.com",
  "otp": "482913"
}
Response{
  "success": true,
  "data": {
    "user": { "email": "newparent@example.com", ... },
    "accessToken": "eyJhbG..."
  }
}
POST /auth/family-members Bearer JWT

Parent adds a child. PIN rules depend on age (see docs/FAMILY-CHILD-PIN.md).

AgePIN formatRequired?
≤ 64-character emoji PIN (e.g. 🌟🎈🐻🎨) or 4 digitsOptional
> 64 numeric digits onlyYes
 
Request — child age 5 (emoji PIN){
  "name": "Sara",
  "age": 5,
  "pin": "🌟🎈🐻🎨",
  "emojiOption": 2
}
Request — child age 8 (numeric PIN){
  "name": "Omar",
  "age": 8,
  "pin": "4829"
}
Response{
  "success": true,
  "data": {
    "user": { "id": "...", "name": "Sara", "age": 5, ... },
    "autoSignInUrl": "https://api.example.com/auth/auto-signin/..."
  }
}

Admin dashboard Admin JWT

Admin routes are grouped separately in Swagger under Admin Dashboard. Obtain a token via POST /admin/auth/login (not app /auth/login).
POST /admin/auth/login Admin 
Request{ "email": "admin@neyome.com", "password": "..." }
Response{
  "success": true,
  "data": { "accessToken": "...", "user": { "isAdmin": true, ... } }
}
ProfileGET /admin/auth/me
Authorization: Bearer <admin-token>
