Neyome REST API

All endpoints require header x-api-key: <API_KEY>. Responses are shaped as { success: boolean, data: any, message: string }. Open Swagger UI

Conventions

  • Pagination params: ?page=1&limit=20&sortBy=createdAt&sortOrder=DESC
  • ID format: uuid
  • Soft deletes: delete endpoints perform soft delete

Users

GET /users?name=ali&email=@gmail.com&page=1&limit=10&sortBy=createdAt&sortOrder=DESC
curl -H "x-api-key: $API_KEY" "http://localhost:3000/users?name=ali&email=@gmail.com&page=1&limit=10&sortBy=createdAt&sortOrder=DESC"
# Response
{ "success": true, "data": { "items": [/* User[] */], "total": 1, "page": 1, "limit": 10 }, "message": "Users fetched" }
GET /users/:id
curl -H "x-api-key: $API_KEY" http://localhost:3000/users/8f6a9c0e-...
# Response
{ "success": true, "data": {/* User */}, "message": "User fetched" }
POST /users
curl -H "Content-Type: application/json" -H "x-api-key: $API_KEY" -d '{
  "id": "8f6a9c0e-4c7a-4c72-8a3d-1b3fc0f0aa11",
  "name": "Ali",
  "email": "ali@example.com",
  "familyId": "2f1a9f4e-1111-2222-3333-aaaaaaaaaaaa"
}' http://localhost:3000/users
# Response
{ "success": true, "data": {/* User */}, "message": "User created" }
PATCH /users/:id
curl -X PATCH -H "Content-Type: application/json" -H "x-api-key: $API_KEY" \
  -d '{ "name": "Ali Updated" }' http://localhost:3000/users/8f6a9c0e-...
# Response
{ "success": true, "data": {/* User */}, "message": "User updated" }
DELETE /users/:id
curl -X DELETE -H "x-api-key: $API_KEY" http://localhost:3000/users/8f6a9c0e-...
# Response
{ "success": true, "data": {"id":"8f6a9c0e-..."}, "message": "User deleted" }
